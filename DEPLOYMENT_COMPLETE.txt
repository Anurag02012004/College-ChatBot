┌──────────────────────────────────────────────────────────────────────────────┐
│  🆘 TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

Problem: "Module not found" on Render
  → Check requirements.txt has all dependencies
  → Rebuild on Render dashboard

Problem: "Cannot connect to server" on frontend
  → Verify API URL in static-frontend/index.html
  → Check Render backend is running (not sleeping)
  → Test backend directly: curl https://your-app.onrender.com/api/health

Problem: First request very slow
  → Normal for Render free tier (cold start)
  → Wait 30-60s for first request
  → Subsequent requests are fast

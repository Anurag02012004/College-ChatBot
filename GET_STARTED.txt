────────────────────────────────────────────────────────────────────────

   python3 app.py

   Option C - Command Line:
   python3 chatbot_model.py

   Option D - Full Demo:
   python3 demo.py

Problem: Dependencies not installing
Solution: Make sure Python 3.8+ is installed
          pip install --upgrade pip
          pip install -r requirements.txt

Problem: Port 5000 already in use
Solution: Change port in app.py to 5001 or 8000

Problem: Model download is slow
Solution: Normal on first run (~100MB download). Wait patiently!

Problem: Chatbot gives generic responses
Solution: This is normal for questions outside college topics
          Try specific questions about IIIT Kalyani
